本项目聚焦小红书饰品赛道内容同质化严重、爆款逻辑模糊、内容转化波动大、用户种草决策链路不清晰等真实业务痛点，依托社区内容互动数据、电商交易数据、用户问卷量化数据，搭建一套全链路数据驱动的决策洞察与策略优化体系，区别于传统经验式运营，实现从数据复盘、用户洞察、归因分析到策略落地的完整闭环。
项目通过多维度热度、竞争度、转化表现量化研判，完成高潜力细分赛道数据化筛选；针对笔记投放效果开展多维归因，沉淀可复用的高转化标题、内容结构与标签模板，并搭建「AI辅助生成+约束校验+人工复核」人机协同工作流，提升内容迭代效率与质量稳定性。依托28份有效脱敏问卷样本，量化拆解用户种草浏览、信息比对、决策下单的完整行为路径，结合店铺售后、履约数据交叉验证，精准定位物流时效、售后体验等业务卡点，输出可落地的优化方案。
最终沉淀适配小红书社区+电商双场景的标准化分析流程、内容资产与业务策略，形成可复用的社交电商精细化决策洞察方案，具备完整的数据分析、用户洞察、策略迭代与业务落地能力。
Tech Stack：Excel数据透视与可视化、数据清洗、多维归因分析、用户行为量化研究、AI工作流搭建、商业决策洞察
